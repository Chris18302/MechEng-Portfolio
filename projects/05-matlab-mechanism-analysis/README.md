# Planar Mechanism Analysis in MATLAB

## Executive Summary

Used MATLAB to analyze planar mechanism motion and mechanical performance, including position relationships, torque/power behavior, and design-variable evaluation. The project demonstrates numerical engineering analysis, but it needs stronger artifacts and validation before it would compete with HVAC/MEP, energy, commissioning, or BAS-focused work for a featured portfolio slot.

## Technical Scope

- Four-bar / geared five-bar mechanism analysis
- Position and motion relationships
- Torque and power calculations
- Gear-ratio / design-variable evaluation
- Numerical solution and visualization

## Current Result

The project demonstrates MATLAB-based mechanism analysis, but the existing documentation does not yet provide enough plots, assumptions, or validation evidence to support a strong results-oriented engineering case study.

## Skills Demonstrated

MATLAB · Kinematics · Mechanisms · Numerical methods · Engineering computation · Design-variable evaluation
