P-06 Controls / Simulink

Objective

Model and tune a feedback controller for XY tracking performance.

Work completed

A Simulink control model was tuned from an initial low-gain setup toward a stronger proportional/derivative response. Example tuning explored P = 30, D = 3, N = 40 to improve trajectory tracking.

Engineering focus

  • Feedback-controller tuning.
  • Desired versus actual trajectory tracking.
  • Tracking-error reduction.
  • Tradeoffs between controller aggressiveness and response behavior.
