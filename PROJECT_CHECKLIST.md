# Project Upload Checklist

For every new engineering project, include:

- [ ] Problem / objective
- [ ] Engineering requirements
- [ ] Assumptions
- [ ] Diagram or CAD screenshot
- [ ] Equations / method
- [ ] Test or simulation procedure
- [ ] Raw data or source files
- [ ] Results plots / tables
- [ ] Engineering interpretation
- [ ] Error / uncertainty / limitations
- [ ] What you would improve next
- [ ] 1 resume bullet
- [ ] No confidential employer/customer information
