# Impeccable workflow for this portfolio

This project uses the public Impeccable design workflow as a maintenance guide.

Recommended sequence when using a compatible coding agent:

1. `npx impeccable install`
2. `/impeccable init`
   - Surface: **brand**
   - Type: **portfolio**
   - Use the existing `PRODUCT.md` and `DESIGN.md` as the source of truth.
3. `/impeccable critique landing`
4. `/impeccable adapt landing`
5. `/impeccable audit landing`
6. `/impeccable polish landing`

For larger redesigns, use `/impeccable shape` before `/impeccable craft`.

## Portfolio-specific guardrails

- Do not turn the site into a generic software portfolio.
- Preserve factual engineering wording.
- Keep employer work sanitized.
- Prioritize project evidence over visual effects.
- Do not add technologies or claims unless they are supported by actual experience or completed projects.
